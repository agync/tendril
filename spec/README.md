# Tendril Specifications

Normative wire, pairing, capability grant, and relay specifications for Tendril.

- Wire profile specification (preamble, framing, Noise handshake, transport envelope)
- Pairing ritual and channel-binding proof specification
- Capability grant format, canonical signing, delegation, and revocation rules
- Relay forwarding specification
- `vectors/`: canonical, language-agnostic conformance test vectors
