Reach port mapping, bind addresses and the n0 alias from every surface. The CLI gains --p2p-no-port-mapping and a repeatable --p2p-bind, the C ABI, Python and Node transport JSON gain p2p_port_mapping and p2p_bind_addrs, and an invalid bind address is a configuration error naming the key. HintDialers::with_provider_dialer now returns a Result and rejects a P2p or Relay dialer instead of ignoring it.
